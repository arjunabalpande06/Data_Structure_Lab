# 💻 Data Structures Lab

A collection of Data Structures laboratory programs implemented in C, covering fundamental data structures, operations, and algorithmic techniques.

## 📌 About the Repository

This repository contains practical implementations of various Data Structures concepts as part of the academic laboratory coursework.

It focuses on understanding how data is organized, stored, accessed, and manipulated efficiently using different data structures.

The programs are implemented in C to develop strong programming fundamentals and understand the practical applications of data structures.

## 🎯 Objectives

- Understand fundamental data structures.
- Learn different methods of data organization.
- Implement linear and non-linear data structures.
- Perform insertion, deletion, searching, and traversal operations.
- Understand stack and queue operations.
- Implement linked lists and trees.
- Explore sorting and searching techniques.
- Analyze the efficiency of data structure operations.

## 🚀 Getting Started

### Prerequisites

Install the following:

- GCC Compiler
- Visual Studio Code or any C IDE
- Windows, Linux, or macOS

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/Data_Structure_Lab.git
```

### 2. Navigate to the Project Directory

```bash
cd Data_Structure_Lab
```

### 3. Compile a C Program

```bash
gcc 1.1.1.c -o output
```

### 4. Execute the Program

**Linux / macOS:**

```bash
./output
```

**Windows:**

```bash
output.exe
```

Replace `1.1.1.c` with the desired practical file.
